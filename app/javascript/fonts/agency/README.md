# Loco Lokal interface fonts

These Latin-subset WOFF2 files are copied from the agency website's locally
built font assets (`loco-lokal-website/website/.output/public/_fonts/`). They
are bundled by Webpack and served from the application; no external font
requests are made.

- Anybody: normal and italic variable fonts, weights 700–900, width 50–150%.
- Space Grotesk: normal variable font, weights 500–700.

The accompanying SIL Open Font License files come from the Google Fonts
`ofl/anybody` and `ofl/spacegrotesk` directories. Keep them with these assets.

These fonts style the interface. PDF generation and authored document fonts
remain controlled by the existing document-processing code.
